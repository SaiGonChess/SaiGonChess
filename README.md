# SAIGONCHESS.NET

Phần mềm Cờ tướng bản quyền trên nền Web

## 🎯 Tính năng

- ✅ Giao diện responsive, tự động điều chỉnh trên mọi thiết bị
- ✅ Hỗ trợ nhiều engine cờ tướng: Tiểu Trùng, Fairy Stockfish, Toàn Phong
- ✅ Tích hợp AI hiện đại (AlphaZero, NNUE)
- ✅ Giao diện tiếng Việt
- ✅ Kết nối dữ liệu đám mây

## 🚀 Cài đặt

1. Clone repository:
```bash
git clone https://github.com/SaiGonChess/SaiGonChess.git
cd SaiGonChess
```

2. Thêm logo và assets:
   - Thêm file `swphone/logo.gif` (logo của bạn)
   - Thêm file `swphone/favicon.ico` (favicon)
   - Thêm file `swphone/bg.jpg` (background image cho Open Graph)

3. Mở file `index.html` trong trình duyệt hoặc deploy lên web server

## 📁 Cấu trúc thư mục

```
SaiGonChess/
├── index.html              # Trang chủ responsive
├── swphone/
│   ├── style.min-1.1.css  # CSS tối thiểu
│   ├── rightIcon.svg      # Icon mũi tên
│   ├── logo.gif           # Logo (cần thêm)
│   ├── favicon.ico        # Favicon (cần thêm)
│   └── bg.jpg             # Background (cần thêm)
└── README.md
```

## 🎨 Tính năng thiết kế

### Responsive Design
- Logo tự động scale từ 1200px xuống 600px trên mobile
- Buttons có padding và font-size phù hợp với từng màn hình
- Layout flexbox tự động chuyển từ 2 cột sang 1 cột trên mobile

### Styling
- Gradient backgrounds với backdrop blur
- Hover effects trên buttons
- Lazy-loading video YouTube
- Custom play button với glow effect

### Accessibility
- Viewport meta tag cho mobile
- Touch-friendly button sizes
- No-cache headers để đảm bảo cập nhật mới nhất
