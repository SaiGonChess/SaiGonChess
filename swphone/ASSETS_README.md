# Assets Required

Please add the following files to complete the website:

1. **logo.gif** - Logo của SaiGonChess (GIF hoặc PNG format)
   - Kích thước đề xuất: 1200px width
   - Sẽ tự động scale responsive

2. **favicon.ico** - Icon hiển thị trên tab browser
   - Kích thước: 16x16, 32x32, hoặc 48x48 pixels

3. **bg.jpg** - Background image cho Open Graph (khi share trên social media)
   - Kích thước đề xuất: 1200x630 pixels

## Lưu ý:
- Nếu không có logo.gif, website sẽ hiển thị broken image
- Có thể thay thế .gif bằng .png hoặc .jpg trong file index.html
- SVG icons (rightIcon.svg) đã được tạo sẵn
